# ClickerApp (SwiftUI + SwiftData)

Simple iOS click counter app with two screens:

- **Main**: big "Click" button and today's total.
- **Dashboard**: clicks-per-day chart, today's hourly chart, and today's timestamps.

## Tech stack

- SwiftUI for UI
- SwiftData for local persistence
- Charts for visualizations

## Project layout

- `ClickerApp/Models` data models
- `ClickerApp/ViewModels` analytics helpers
- `ClickerApp/Views` app screens
- `ClickerApp.xcodeproj` Xcode project

## Requirements

- Xcode 15+
- iOS 17+ deployment target
